# Patterns

Learn techniques here. Each pattern folder typically includes:

- `README.md` — intuition, visuals, mistakes, interview tips
- `template.py` — reusable skeleton
- `problems-solved.md` — links to problems (not full solution copies)
- `examples.ipynb` — optional dry runs

## How to use

1. Read the pattern README and study the template
2. Solve a related problem under [`../problems/`](../problems/)
3. Link it from that pattern’s `problems-solved.md`
