# Problems

One folder per LeetCode problem, grouped by **primary** topic.

| Topic | Path |
|-------|------|
| Arrays | [arrays/](arrays/) |
| Stack | [stack/](stack/) |
| Linked List | [linked_list/](linked_list/) |
| SQL | [sql/](sql/) |
| Math / DP | [math/](math/) |
| Bit Manipulation | [bit_manipulation/](bit_manipulation/) |

## Convention

```text
problems/<topic>/NNNN-problem-slug/
├── README.md      # problem statement + notes
└── NNNN-....py    # solution (.py / .java / .sql)
```

Link solved problems from the matching pattern’s `problems-solved.md` under [`../patterns/`](../patterns/).
